CODERX GAMER - FULL STACK PHP PROJECT

Acode:
1. Extract this folder.
2. Open the folder in Acode.
3. Make sure PHP + SQLite are available on your Android PHP server app.
4. Start a local PHP server pointing to this folder.
5. Open index.php through the server URL.

Admin demo:
admin/index.php?key=foreveradmin

Important:
Acode is the editor. It does not itself execute PHP. You need a PHP server app on Android.
The included database.sqlite is created and ready; config.php also creates missing tables automatically.
